The project is built with a focus on **Java backend development, REST APIs, database management, authentication, and scalable application architecture**.

**Key Areas:**

* 🔐 User authentication and authorization
* 💳 Subscription management
* 📦 Subscription/service management
* 🔄 Subscription lifecycle handling
* 🌐 RESTful API architecture
* 🗄️ Persistent database management
* 🏗️ Layered backend architecture
* ⚙️ Business logic implementation
* 🔒 Secure backend request handling

### 🏠 Wander-Lust

A full-stack rental listing platform built with **Node.js, Express.js, MongoDB and EJS**.

**Key Features:**

* 🔐 User authentication and authorization
* 🏡 Property listing CRUD operations
* ⭐ Review functionality
* 👤 Owner-based authorization
* ✅ Joi validation
* 🍪 Session management
* 💬 Flash messages
* 🗄️ MongoDB relationships using Mongoose
